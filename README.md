A Python program that writes one sentence explaining the modern internet to a traveler from the year 1800 — built only from things a person of 1800 already knows (a road, a post office, a library) — to `/output/entry.txt`, for make.fun's "One Sentence for a Traveler from 1800" bounty. The sentence: a road joining every post office and library on earth, so any letter or book you ask for reaches your door in a blink, sent by light itself.

## Run it

```sh
python3 main.py
```
